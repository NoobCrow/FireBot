# Tools
| Script | Purpose |
|---|---|
| `servo_celibration.py`, `set_zero.py` | Interactive servo centre and range calibration |
| `pantest.py`, `tilttest.py`, `hose_test.py` | Single-servo motion tests |
| `pump_test.py`, `motor_test.py` | Relay/pump and motor driver tests |
| `live_view.py`, `live_fire.py` | Live detection preview (FPS counter, LEFT/CENTER/RIGHT) |
| `ncnn_test.py`, `ncnn_camera_test.py` | NCNN model sanity checks |
| `test_gpu.py` | CUDA check on the training machine |
| `legacy_ultrasonic/` | Earlier prototype scripts with HC-SR04 ultrasonic ranging (removed in the final design) |
